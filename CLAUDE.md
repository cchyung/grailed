# Grailed listing repo

Tools and Claude skills for photographing, pricing and listing clothes on Grailed.

- First time on this machine: run the `grailed-setup` skill.
- A listing batch: `grailed-listing` (it loads `grailed-photos` for the photo phase).
- Python is always `.venv/bin/python`.
- `listings.json` is the only data file edited by hand. `listings.md` is generated by `tools/build_md.py`.
- Run data (`listings.*`, `picks.json`, `pricing.md`, `measurements.csv`, `research.md`, `config.local.json`), `photos/` and `.env` are gitignored and belong to whoever is selling. Don't commit them, and don't put seller names, addresses, account IDs or artifact URLs into tracked files. Templates for the data files are in `examples/`.
